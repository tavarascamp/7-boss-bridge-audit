each vault works with one token.

How verification works:

1.  Take the private key plus message (The data, function selectors and other params)
2.  Smash it into elliptic curve Digital Signatures Algorithm(ECDSA) in a formated way
    - The outputs here are v,r,s
    - Then we can use this values to verify soeones signatures with `ecrecover`


Step by step
  - Get the signed message
  - Break into v,r,s
  - Get the data itself
  - Use it as input params for `ecrecover`
